# Gramps Render Template

A production-ready deployment template for running Gramps Web on Render.

## Goals

- One-click Render deployment
- No Docker Compose
- Managed PostgreSQL
- Managed Redis
- Object storage for media
- Cloud-native architecture
- Automatic updates
- Comprehensive documentation

## Project Status

🚧 Early development

## Planned Features

- Render Blueprint
- Health checks
- Automatic database migration
- Cloudflare R2 integration
- GitHub Actions
- Backup scripts
